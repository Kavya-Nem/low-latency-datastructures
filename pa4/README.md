## Files

- Sparse.c
  Main program. Reads an input file, extracts dimension of matrix and the number of non-zero values. Then, it populates two matrices with given values and performs 8 mathematical operations on both the matrices. Finally, it prints the output of all the operations done.

- Matrix.c
  Implementation of the Matrix ADT which can perform addition, subtraction, and multiplication on two matrices.

- Matrix.h
  Header file for the Matrix ADT. Defines the Matrix type and all the exported operations.

- MatrixTest.c
  Test client used to verify correctness of all the Matrix ADT operations.

- List.c
  Implementation of the List ADT using a doubly linked list with cursor.

- List.h
  Header file for the List ADT. Defines the List type and all the exported operations.

- Makefile
  Builds all .c files and includes a clean target.
