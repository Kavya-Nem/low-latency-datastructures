## Files

- Words.cpp
  The top-level client that reads an input file, extracts unique words as keys, assigns their insertion order as values, and outputs the alphabetized Dictionary.

- Dictionary.cpp
  Implementation of the Dictionary ADT using a Binary Search Tree. Includes helper functions for traversals and tree manipulations.

- Dictionary.h
  Provided header file containing the Dictionary ADT interface, private Node struct, and method declarations.

- DictionaryTest.cpp
  A comprehensive test client written to independently verify the functionality of the Dictionary ADT, checking insertions, deletions, iterations, and edge cases.

  Lists the files submitted in assignment along with purpose of each file.

- Makefile
  Builds all .cpp files and includes a clean target.
