## Files

- WordFrequency.c
  Main program. Reads an input file, extracts words, and adds them to a dictionary along with frequency, or updates frequency if the word already exists inside of the dictionary. Finally, it prints the string representation of the dictionary to the output in form "key : value" in the keys' insertion order.

- Dictionary.c
  Implementation of the Dictionary ADT which can create, free, clear, set values, remove keys, copy, check equality, and print standard or diagnostic output of a dictionary type.

- Dictionary.h
  Header file for the Dictionary ADT. Defines the Dictionary type and all the exported operations.

- DictionaryTest.c
  Test client used to verify correctness of all the Dictionary ADT operations.

- README.md
  Lists the files submitted in assignment along with purpose of each file.

- Makefile
  Builds all .c files and includes a clean target.
